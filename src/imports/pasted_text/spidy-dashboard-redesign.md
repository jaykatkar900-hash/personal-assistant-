Redesign the existing SPIDY Personal AI dashboard into a premium futuristic AI command-center interface.

IMPORTANT:
- Use the existing dashboard as the structural/content reference.
- Keep all existing information, labels, metrics, modules, and functionality.
- Do NOT include a Windows taskbar, desktop background, browser chrome, or operating-system UI.
- The final design must be a standalone web application filling the entire viewport.
- Preserve the SPIDY identity and futuristic cyber-AI aesthetic, but make the UI cleaner, more polished, modern, and production-ready.
- Desktop-first responsive layout at 1440px–1600px width.

VISUAL STYLE:
- Dark navy/near-black background (#030812 style).
- Premium sci-fi HUD aesthetic inspired by modern AI control rooms.
- Use glassmorphism panels with subtle transparency.
- Thin cyan/blue borders with subtle outer glow.
- Accent colors: electric cyan, bright blue, violet/purple, and small amounts of green for online/success states.
- Strong visual hierarchy and excellent spacing.
- Avoid excessive glow; use glow selectively for important interactive elements.
- Use clean futuristic typography, similar to Space Grotesk / Orbitron / Inter.
- Rounded corners around 8–14px.
- Add subtle grid, circuit-board, and radial HUD details in the background without making the interface noisy.
